# 从「发现赚钱机会」到「这是 Jaredfromsubway」——一次链上分析的自白

## 第一章：发现

一切从 Dune 上的一笔查询开始。

地址 `0xae2fc483527b8ef99eb5d9b44875f005ba1fae13`，30 天手续费收入 **$133,719**。没有方向性持仓，纯做市。年化 30%+ 的稳定收益？

看起来像是一个专业的 Uniswap V3 集中流动性做市机器人。值得拆解、学习、复现。

我们开始拉数据。

## 第二章：逆天数据

### 2.1 交易量

```
30 天事件数:  753,420 笔
独立交易:    171,810 笔（日均 5,727 笔）
手续费收入:   +$133,719
```

日均近 6000 笔交易。这不是人能做到的。

### 2.2 极窄区间

**USDC/USDT** 的仓位宽度是 **1 tick = 0.01%**——Uniswap 允许的最窄值。相当于在 1.0000 到 1.0001 之间放 $150 万。

更离谱的是，它在 200+ 个不同的 tick 位置上重复这个操作，每天轮换。不是 1 个仓位，是同时管 5 个，每天开关 200 次。

### 2.3 大小不一的仓位

```
$111K  → ETH 单边仓位
$380K  → ETH/sato 混合仓位
$520K  → ETH 单边仓位
$581K  → ETH 单边仓位
$1.06M → sato/USDT 均衡仓位
$2.05M → sato/USDT 单边（纯 USDT 卖单）
```

从 11 万到 205 万，横跨 20+ 个池子。总资金规模约 $5M。

### 2.4 持仓时长

| 池 | 平均持仓时长 |
|---|------------|
| ETH/Pizza（土狗） | **11 分钟** |
| USDC/USDT（稳定对） | **11 小时** |
| sato/USDT | **11.7 小时** |

波动越大的币，持仓越短。不是随机操作，是高度系统化的。

### 2.5 交易结构

每一笔交易不是简单的 LP 操作，而是：

```
REMOVE 旧 LP 仓位
  → SWAP SPCX→WETH（套利）
  → SWAP USDT→USDS（Curve 三角）
  → SWAP USDT→sato（补库存）
  → ADD 新 LP 仓位
  → SWAP WETH→XYO→WETH（剥头皮）
```

一笔交易串起 Uniswap V2、V3、V4、Curve、1inch，五个协议。99.3% 的交易是多步骤的。

### 2.6 不对劲

LP 做市不需要这么复杂的交易结构。如果你只是做市，REMOVE→ADD 就够了，为什么要顺便刷 SPCX 对倒、Curve 三角、XYO 剥头皮？

这些操作不像在做市，更像在**收割什么东西**。

## 第三章：真相

查了一下，这个地址是 **Jaredfromsubway**——以太坊最大的 MEV 机器人。

那一切都说得通了：

```
LP 仓位 ≠ 做市工具
LP 仓位 = MEV 策略的基底 + 资金停泊位
```

**为什么 LP 操作这么频繁？**
不是因为他勤快，是因为 MEV 机器人需要持续扫描 mempool，每次扫描发现机会就顺便刷新一下 LP。LP 操作是「顺便做的事」，不是主业。

**为什么同一笔交易里塞那么多套利？**
不是因为他贪心，是因为这些操作本身就是 MEV 提取——SPCX 对倒是在夹用户的交易，Curve 三角是在收割稳定币价差，XYO 刷单是在跑统计套利。

**为什么仓位大小不一？**
大的仓位（$2M）是长期资金停泊，收点手续费等 MEV 机会。小的仓位（$111K）是在特定池子做夹子需要的前置资金。

**为什么持仓时长差这么多？**
土狗币（ETH/Pizza）交易活跃、MEV 机会多，所以频繁操作。稳定对 MEV 机会少，仓位放着不动收租就行。

## 第四章：放弃（但没完全放弃）

这个地址的策略不能直接复现——MEV 需要节点基础设施、mempool 访问、竞争激烈的抢跑市场，不是一个人写个脚本就能跑的。

但可以学习的东西：

1. **资金效率思维**：他的 LP 操作不是为了做市，而是让闲置资金在等 MEV 机会时也能赚钱。这条思路通用——任何 DeFi 策略都可以考虑资金永不闲置。

2. **Gas 共享机制**：V4 multicall 让一次 gas 支撑 5+ 个操作。这个思路可以用在合法策略上——LP refresh 是刚需，顺手做的操作 gas ≈ 0。

3. **窄区间 + 高周转**：集中流动性做市的本质就是高频搬家，这不是缺点，是资金效率的来源。

4. **多协议路由**：一笔交易走 5 个协议，说明链上流动性是高度可组合的。这个思路可以用在任何做市策略中。
