## 三、市场隐含的世界状态

由三个 Arsenal 市场的 Yes 价格推导出四种互斥状态的概率：

```
                      ┌─ UCL Yes (41.5%)
                      │
           ┌──────────┼──────────┐
           │  36.6%   │   4.9%   │
           │  双冠王   │  仅欧冠   │
           │          │          │
EPL 79.5%  ┤──────────┼──────────┤
           │  42.9%   │  15.6%   │
           │  仅英超   │ 四大皆空  │
           │          │          │
           └──────────┴──────────┘
```

**推导过程**：

```
P(Trophy) = P(EPL ∪ UCL) = P(EPL) + P(UCL) - P(EPL ∩ UCL)
0.8445     = 0.795   + 0.415   - P(双冠)

→ P(双冠)   = 0.795 + 0.415 - 0.8445 = 0.3655  (36.6%)
→ P(仅英超) = 0.795 - 0.3655          = 0.4295  (42.9%)
→ P(仅欧冠) = 0.415 - 0.3655          = 0.0495  ( 4.9%)
→ P(无冠)   = 1 - 0.8445             = 0.1555  (15.6%)
```

### 隐含条件概率

| 条件 | 概率 | 解读 |
|------|------|------|
| P(UCL \| EPL) | 36.6% / 79.5% = **46.0%** | 拿英超后欧冠胜率翻倍 |
| P(UCL \| ~EPL) | 4.9% / 20.5% = **24.1%** | 不拿英超则欧冠希望大降 |
| P(EPL \| UCL) | 36.6% / 41.5% = **88.1%** | 拿欧冠几乎意味着双冠 |
| P(EPL \| ~UCL) | 42.9% / 58.5% = **73.3%** | 没拿欧冠仍有七成英超 |

> 市场赋予了英超和欧冠之间极高的正相关性。实际上 EPL 收官（5/24）和 UCL 决赛（5/30）只隔 6 天，两场硬仗的体能消耗应该是**负相关因素**，但市场却在定价"赢一场就更可能赢第二场"。

## 四、套利分析

### 4.1 negRisk 池内套利

| 池 | ΣYes | 方向 | 理论收益 | 实际可行性 |
|----|------|------|----------|------------|
| EPL Winner | 0.990 | 买全部 Yes | +1.0% | 需 20 笔交易，gas > 利润 |
| UCL Winner | 1.015 | 卖全部 No | +0.025% | 需 60 笔，57 个已淘汰的 No=$1 无利差 |
| EPL 2nd Place | 0.996 | 买全部 Yes | +0.4% | 同上，gas 问题 |

**结论：negRisk 池内套利在数学上存在，但 Polymarket Polygon 链上的 gas 成本 + 滑点将利润蚕食至零。**

### 4.2 跨市场套利

三个 Arsenal 市场**不属于同一 negRisk 组**。构造线性规划：

设 x1~x6 分别为 EPL-Y, EPL-N, UCL-Y, UCL-N, Trophy-Y, Trophy-N 的持仓数。

四种状态下等额支付的约束：

```
(EPL, UCL):     x1 + x3 + x5 = V
(EPL, ~UCL):    x1 + x4 + x5 = V
(~EPL, UCL):    x2 + x3 + x5 = V
(~EPL, ~UCL):   x2 + x4 + x6 = V
```

解得：x1=x2, x3=x4, x5=x6。即**必须在每个市场上同时做多和做空**。

总成本 = x1(0.795+0.205) + x3(0.415+0.585) + x5(0.8445+0.1555) = x1 + x3 + x5
总收益 = x1 + x3 + x5

→ **零利差。中点价不存在跨市场套利。**

### 4.3 为什么没套利但看起来有？

三个市场的中点价满足概率论的基本约束（Kolmogorov 公理）。价格的"缝隙"不在中点价，而在：

- **Bid/Ask Spread**：实际成交价偏离中点 1-3 美分
- **流动性不均**：Trophy 市场只有 $325K vol，大单会推动价格
- **手续费**：maker 0.1% / taker 0.1%

## 五、结构性发现

### 5.1 流动性极度失衡

```
EPL Winner  (Arsenal 子市场):  $11.1M vol
UCL Winner  (Arsenal 子市场):  $6.7M  vol
Trophy      (独立市场):       $0.33M vol  ← 比前两者小 20-30 倍
```

一个 $325K 的小池子，在给 $18M 的大池子当"衍生品定价锚"。**几万元的买卖就能推动 Trophy 价格几个百分点**，而它反过来又影响市场对 P(双冠) 的隐含估计。

### 5.2 缺少"双冠王"市场

Polymarket 有这三个市场，但**没有** "Arsenal to win the Double" 市场。这是最自然的衍生品——三个已有市场隐含双冠概率 36.6%，直接开一个双冠市场可以：

- 为套利者提供更直接的 hedge 工具
- 让 Polymarket 收割新的交易费
- 消除三个分散市场之间的价格摩擦

没有开，可能是事件创建者还没注意到。

### 5.3 UCL 池被多头挤爆的结构性原因

ΣYes = 1.015 是一个值得注意的信号。正常 negRisk 池 ΣYes ≈ 0.98-0.995（被手续费压到 1 以下）。超买的原因：

1. 57 个已淘汰队伍的 Yes 被精准打到 0.00，没有卖家
2. 剩余 3 个热门队被多军抢筹，推高了整体 ΣYes
3. 没有人做空已淘汰队伍的 Yes（反正快结算了，占用资金不划算）

这导致 ΣYes 在决赛阶段系统性偏高——这是 negRisk 机制在赛事末期的**结构性特征**，不是套利机会。

### 5.4 隐含相关性可能过高

市场定价：赢一场 → 另一场胜率翻倍（24% → 46%）。

足球现实：EPL 最后三轮 + UCL 决赛集中在 10 天内，体能消耗、伤病风险、心理压力都是**负相关驱动因素**。如果真实相关性低于市场隐含值，那么：

- **Trophy No @ 15.6% 被低估**（真实概率可能更高）
- **EPL Yes + UCL Yes 同时持有**有正的期望收益，但承担了过多相关性风险
